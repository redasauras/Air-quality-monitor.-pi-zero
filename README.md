# Raspberry Pi Air Quality Tracker

A DIY air quality monitoring project built around a Raspberry Pi Zero W. This project is designed to make monitoring indoor air quality simple, affordable, and accessible to anyone.

The system uses environmental sensors to collect live air quality data and displays the results through a web-based dashboard that can be accessed from devices on your local network.

## Features

- **Live monitoring:** View current air quality and environmental readings.
- **Historical data:** Store readings and view trends over time.
- **Graphs:** Explore air quality history with different time ranges.
- **Air quality guidance:** Get helpful information about indoor conditions.
- **Reports:** View daily and weekly summaries.
- **Alerts:** Identify changes and unusual trends in air quality.
- **3D-printed enclosure/model:** A printable design to house the project hardware.

## Hardware

- Raspberry Pi Zero W
- BME280 environmental sensor
- PMSA003I particulate matter sensor
- 3D-printed enclosure and mounting components

## Software

- Python
- Flask web server
- SQLite database
- HTML, CSS, and JavaScript dashboard

## Getting Started

The goal of this project is to make it easy for others to build their own air quality tracker. You can use the source code and 3D model as a starting point, customize the design, and adapt the project to your own setup.

Hardware configurations and software may need adjustments depending on the components you use.
